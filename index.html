> PROJETOS

Filmes e Jogos Favoritos (Projeto Prático)

Página desenvolvida com HTML e CSS puro para organizar uma lista pessoal de filmes e jogos favoritos em formato de catálogo. O projeto apresenta cards com imagens, categorias, informações básicas e descrições curtas sobre cada título escolhido.

O objetivo foi praticar seções, uso de imagens, layout em cards, responsividade e pequenos efeitos visuais com CSS, como a troca da imagem do jogo por um GIF ao passar o mouse. Mais informações dentro da página do projeto.

Landing Page para Negócio Local (Atividade de Extensão)

Projeto desenvolvido com HTML, CSS e JavaScript básico para a Latos Mídia, empresa local de design, social media e produção audiovisual. A proposta foi criar uma landing page institucional para apresentar a marca, seus serviços, portfólio de trabalhos e canais de contato.

O principal desafio foi adaptar a página à identidade visual minimalista da marca, respeitando suas cores e estilo, sem perder a objetividade, a funcionalidade e a navegação simples.
